# whisper Android preview

独立安装的 Android 首版，不需要同时运行 Mac。

- 离线演示私聊、群聊、流式输出与停止；演示不是本地大模型。
- 用户可以显式配置其他厂商的 OpenAI-compatible HTTPS API；真实调用会使用该厂商的账户额度。
- 会话保存在手机应用私有目录。凭据默认仅在内存；保存和恢复均需单独确认。
- ChatGPT 安卓登录、远程电脑配对和手机控制尚未接入；本版本不申请无障碍、录屏或共享存储权限。

需要 Android 8.0 / API 26 或更新系统。下载附件中的 `whisper-…-android.apk`，通过系统安装界面确认安装来源；不要关闭系统安全保护。无需下载源码压缩包。

附件提供 APK 的 SHA-256 和签名验证记录。后续同包名版本将使用相同的独立发布签名，以支持覆盖更新。
