# whisper v0.3.0 · Chrome 登录 ChatGPT

新增安卓 ChatGPT 登录接入：

- 设置 → **通过 Chrome 登录 ChatGPT** → 在 OpenAI 官方页面授权 → 切回 whisper → **读取可用模型**。
- 在聊天的「成员」中选择 ChatGPT 和模型；发送前确认消耗订阅用量。
- 登录默认只在内存。加密保存、恢复登录各自需要明确同意；支持取消和退出。
- 已接入 PKCE、手机本地回调、身份签名校验、令牌续期和 Responses 流式聊天。

需要 Android 8.0 或更新系统。下载 `whisper-v0.3.0-android.apk`，可使用原有签名覆盖更新 v0.2.0。

验证：57 项安卓单元测试（Debug / Release）、10 项 Android 35 模拟器测试、125 项桌面回归通过；Lint 无错误。Chrome 到手机回调已用合成授权数据验证。

**真实 OpenAI 账号授权和订阅用量尚待用户验收。** 测试没有登录真实账号或发送真实模型请求；实际资格与可用模型由官方授权结果决定。不会继承 ChatGPT 对话、记忆、Dear 身份或私有工具。远程电脑和手机控制尚未接入。

附件提供 APK SHA-256、公开签名验证和构建记录。签名私钥只保存在维护者本机。
